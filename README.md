
# Сервис управления рассылками Django
Курсовая работа по разработке веб-приложения для управления email-рассылками с использованием Django.

## Функциональность
### Основные возможности:
- Управление клиентами - CRUD операции для получателей рассылок

- Управление сообщениями - создание и редактирование шаблонов писем

- Управление рассылками - планирование и контроль email-кампаний

- Отправка рассылок - через веб-интерфейс и командную строку

- Статистика и отчеты - детальная аналитика по отправкам

- Аутентификация - регистрация, вход, управление профилем

- Права доступа - разделение на Пользователей и Менеджеров

- Кеширование - оптимизация производительности

## Статистика на главной
- Общее количество рассылок

- Количество активных рассылок

- Количество уникальных клиентов

## Технологический стек
Backend: Django 6.0

Database: SQLite (для разработки) / PostgreSQL (для production)

Frontend: HTML, Bootstrap 5

Кеширование: Django cache framework

Аутентификация: Django Auth с кастомной моделью пользователя
